# Cloud Eleven ✨

A minimalist, aesthetic clock and calendar web app featuring real-time updates and angel number notifications.

## 🌟 Features
- Real-time clock with seconds
- Dynamic date and mini calendar
- Angel number popups (11:11, 2:22, etc.)
- Smooth glassmorphism UI
- Soft animated background effects

## 🛠️ Tech Stack
- HTML
- CSS (Glassmorphism, animations)
- JavaScript (Date, DOM manipulation)

## 🚀 Live Demo

## 💡 Inspiration
Designed to create a calm, aesthetic experience while subtly integrating “angel number” moments into daily life.
